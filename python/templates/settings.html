Diagnostics

While on, every web player keeps a log of its connection (loads, buffering, stalls, retries, position jumps) and shows a Diagnostics panel with a copy button. The server logs each session's playlist requests and segment downloads under the same session id, so the two sides line up. Costs a little bandwidth per listener; switch it off when done.{% if config.player_debug %} See player.log.{% endif %}
